# christiannsabaka-gpstracker
 This project will contain all the progress and updates for the GPS Tracker Product. The product is a document tracker that will be used by end users attached to their documents (passports, invoices etc) for tracking.

## Project Requirements
1. The tracker will be replaceable. As soon as the battery drains, the user will have to purchase a new tracker device.
2. The required backup is around 1 year minimum and 3 years maximum (This needs to be researched first)
3. The tracker should be able to sound an alarm when triggered by user. There will be two options for prototype; Speaker based approach and buzzer based approach.
4. The tracker will have 4G Modem and also other necessary related peripherals along with GNSS.
5. Type of antenna should be so carefully determined by comparing with reference products.
6. The size of tracker should be as small as possible and should allow user to stick it to their desired document.
7. There should be one button on the PCB for power on/off but that should ask the app first before shutting down the product. Turn on will work straighforward.
8. There should be a red LED on the product.
9. The product cost should be under $10.
10. No on board charging is needed, the tracker will be replaceable.
